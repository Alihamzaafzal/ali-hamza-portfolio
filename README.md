# Ali Hamza — Full Stack Engineer & AI Agent Developer

> Modern, high-performance portfolio featuring 3D WebGL visuals, autonomous AI agent architecture, interactive hardware-accelerated animations, and responsive design.

![Portfolio Preview](/public/ali-hamza.jpg)

## ⚡ Tech Stack & Architecture

- **Frontend & 3D**: React 19, TypeScript, Vite, Tailwind CSS, Three.js, WebGL, GSAP, Framer Motion, Lenis Smooth Scroll
- **AI Agents & LLM**: LangChain, OpenAI & Claude APIs, Function Calling, RAG Pipelines, Python
- **Backend & APIs**: Node.js, Express.js, Laravel PHP, RESTful APIs, WebSockets, JWT/OAuth, RBAC
- **Databases & DevOps**: MongoDB, MySQL, Redis, Git, Vercel, CI/CD

## 🚀 Key Features

- **Cinematic Hero**: 3D orbital gyro mouse parallax, holographic floating portrait card, and particle canvas.
- **System Architecture**: Interactive 4-tier dataflow diagram with live animated SVG signal beams.
- **Sticky Stacking Projects**: 3D perspective tilt cards displaying featured production systems (SimpliFi Go, Insight 3D, Pazvese, Real Software, Skybound Flights).
- **Audio & Micro-Interactions**: Custom synthesized Web Audio effects and cursor particle bursts.
- **Command Palette**: `Ctrl + K` quick navigation HUD with instant keyboard accessibility.
- **Comprehensive Resume**: In-app printable and downloadable HTML/Text resume.

## 🛠️ Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Alihamzaafzal/ali-hamza-portfolio.git
   cd ali-hamza-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
